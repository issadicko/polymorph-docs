# Mon extension

Point de départ d'une extension déclarative de Polymorph. Copiez ce dossier, puis :

1. remplacez `mon-extension` par l'identifiant de votre extension, partout dans `polymorph.json` ;
2. décrivez vos données dans `entites`, vos écrans dans `application` ;
3. ajoutez vos scripts dans `scripts/` et déclarez-les dans `hooks` ;
4. vérifiez et empaquetez : `npm run empaqueter -- chemin/vers/mon-extension`.

Le guide complet : [Votre première extension](https://github.com/issadicko/polymorph-docs/blob/main/src/content/docs/extensions/premiere-extension.md).

Ce fichier entre dans l'archive : l'installation l'ignore, mais il présente l'extension à qui ouvre l'archive.
