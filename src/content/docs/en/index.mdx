## Native extensions

PHP code and a user interface, in a signed archive: their own tables, an API, free-form screens, cards on the records, scheduled tasks. The platform operator deploys it, and each institution installs it as a module.

## Declarative extensions

For simpler needs, with no compiled code: data, generated entry screens, cards and scripts, described in a JSON manifest. The institution's administrator installs it themselves.
